# Search pilot preregistration

**Preregistered:** 2026-08-27
**Starting branch:** `work/card-corpus-extraction`
**Starting HEAD:** `2be8256e2d071f6c8d94d91a323fb231b2aead45`
**Production implementation:** frozen and out of scope

## Purpose

Determine whether the existing large semantic corpus adds unique, source-correct implementation value beyond a compact source-linked contract and tests. This is a falsification experiment, not a demonstration project.

## Locked evidence order

1. Raw rulebook and exact Search card source.
2. Blind baseline generated by `glm-5.3-flash` from supplied raw excerpts only.
3. Concise Markdown rules corpus.
4. Frozen semantic record and related semantic dependencies, inspected only after the baseline is locked.

The semantic corpus, builders, validators, backlog, vocabulary, and ontology may not be edited during this experiment.

## Slice

Search Action-card play through selected Item gain/storage. Post-gain Item use is excluded.

Source excerpts:

- Rulebook lines 2871–2875: zero-cost Play an Action card.
- Lines 3177–3179: reveal, resolve, discard Action card.
- Lines 3188–3191: selected effects must resolve entirely.
- Lines 3543–3548: finite-component fallback.
- Lines 4849–4865: draw per Room Item icon, keep, corresponding deck-bottom return, unchosen secrecy.
- Lines 4899–4904: found Items are fully loaded.
- Lines 4905–4910: regular Item Backpack storage and secrecy.
- Lines 4933–4948 and 5024–5034: Heavy classification/storage/displacement.
- Lines 5045–5057: Armor storage/replacement/failure.
- Exact Search face: body wording and Not In Combat restriction.

## Hypotheses

### H1 — compact-contract sufficiency

A compact source-linked executable contract and acceptance suite will reject every pre-registered production-relevant mutation without importing the semantic corpus.

**Pass:** all mutations M01–M14 are killed or are explicitly blocked because the official source supplies no policy.
**Fail:** any mutation survives as accepted behavior, or a blocked source question is silently defaulted.

### H2 — unique semantic utility

The frozen semantic corpus contains at least one source-correct, implementation-relevant contribution missing from both the blind baseline and concise Markdown, and that contribution kills a production-relevant mutation.

**Pass:** all four semantic utility criteria in `docs/rules/implementation-readiness.md` pass.
**Fail:** no unique contribution exists, the contribution is unsupported/interpretive, or a one-line compact requirement provides the same protection.

## Source-clear scenarios

The executable pilot must cover at least:

1. one green plus one red icon, with exact per-deck draw and return;
2. duplicate icons of one color;
3. duplicate-title physical occurrences remain distinct;
4. regular Item gain to an unlimited secret Backpack;
5. Heavy gain into an empty Hand slot;
6. Heavy gain with occupied Hands and an explicit owner displacement choice;
7. Armor gain into an available Armor position;
8. existing Armor replacement with an explicit owner choice;
9. Action-card reveal/discard lifecycle on successful resolution;
10. Not In Combat rejection without state mutation.

## Explicit blocked scenarios

The reference contract must return a typed unresolved result and leave state unchanged for:

- empty required Item deck (A-1);
- post-random-draw legality/storage interaction (A-2/A-3);
- zero-versus-one keep conflict if no authority decision is encoded (A-7);
- unknown discard destination for displaced/failed gain Items (A-8);
- any visibility claim for non-Backpack stored Items not supported by supplied source (A-5).

## Measurements

- focused test and mutation pass/fail counts;
- executable contract and test lines;
- blind-baseline requirements/ambiguities/scenarios;
- frozen semantic contributions classified as duplicate, unique-supported, unique-unsupported, or non-implementation provenance;
- defects killed uniquely by each layer;
- whether a compact requirement/test can substitute for every claimed semantic benefit.

## Stop conditions

Stop without expanding scope if:

- production files under `js/` would need to change;
- semantic artifacts would need to change to make the pilot pass;
- pilot code/tests exceed 800 lines;
- a new general rule language or framework starts emerging;
- a source ambiguity must be guessed to continue;
- adversarial review identifies a load-bearing flaw that cannot be repaired within this slice.
