# Owner notes — things you should really know (running list)

Kept short. Updated as the autonomous run proceeds. Read this first at the end.

1. **Corpses may be expansion content leaking into base scope.** Two TTS Objective/Mission Task faces (RETRIEVAL, OLD FRIEND) reference "Corpses from the Hibernatorium". No official base-game source mentions corpses; the Gamefound store page lists them only in an add-on pack. Recorded as OQ-013; the faces stay in the corpus as source occurrences with an explicit gap. Decision for you later: keep them in base scope or move them to expansion.
2. **Objective "N+" thresholds / "unavailable if you are number 5" have no in-play rule.** Only the setup filter exists (FND-011). Recorded as OQ-014, no default adopted.
3. **Overwhelming Fire is a Facility-destruction trigger, not just "game ends".** RB p. 23: running out of Fire markers destroys the Facility (everyone inside dies, INT-010). The corpus previously had no fourth end trigger at all; the draft proposal had also dropped the "Facility is destroyed" clause — corrected at application time. This changes the legacy engine's end-condition set.
4. **Fresh verification after repair produces "unsure", not "pass", for source-variant faces with open semantic questions.** Of the first 144 re-verified repairs: 120 pass, 0 fail, 24 unsure. Every unsure says the same thing: the exact card/room text is now in the corpus, but a SEM-Q (Command nesting, Robot movement, Exploration Noise timing, Item-icon glyph, etc.) leaves its operative meaning unsettled. This is the protocol behaving correctly (open question ≠ pass). The audit will therefore close with a larger unsure pool than before; those are the real remaining rules questions, and the list is the natural input for a Q&A round with the publisher / BGG developer account.
5. **Burst precondition tightened.** ACT-BURST-001 now requires the adjacent Corridor to contain an Intruder (RB p. 33 "may only Burst at Intruders in an adjacent Corridor"). The old text allowed selecting any adjacent Corridor. Legacy-engine behavior differs.
