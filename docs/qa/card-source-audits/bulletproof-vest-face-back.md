# Bulletproof Vest TTS face/back audit

- TTS object GUID: `21bd03` (`CardCustom`, Contractor bag).
- FaceURL source: `assets/tts-mod/extract/v2-dl/tree/cards/character/contractor-042.png`.
- BackURL source: `assets/tts-mod/extract/v2-dl/tree/cards/character/contractor-044.jpg`.
- Face transcription: `When you would gain a Serious Wound, discard this Item instead.`
- Back transcription: `When you would receive a Serious Wound, discard this Item instead.`
- Current official rulebook, setup: Contractor starts with two Character Items; Armor is placed in the Heavily Injured section.
- Current official rulebook, page 29: Armor is marked additionally on the top of the card.
- Current official rules terminology uses “gain a Serious Wound.”
- FAQ v1.2 contains no Bulletproof Vest amendment.

Decision: use the TTS FaceURL (`gain`, top Armor marks) as the canonical card face. Retain the BackURL and this audit as provenance for the conflicting variant.
