# Sources and Citation Convention

## Primary sources

- *Nemesis: Retaliation Rulebook*, official PDF, local research copy: `docs/rulebooks/Nemesis_RT_Rulebook_official.pdf`.
- *Nemesis: Retaliation FAQ v1.2*, official PDF, local research copy: `docs/rulebooks/Nemesis_RT_FAQ_v1.2.pdf`.

The PDF files and their text extractions are gitignored because they are publisher materials. This public corpus cites them but does not reproduce them wholesale.

## Citation format

Use the document name and printed/PDF page where available:

- `Rulebook p. 12, “Player Phase”`
- `FAQ v1.2 p. 2, “Closed doors during exploration”`

Where page recovery from the extraction is uncertain, include a locator aid but flag it for manual PDF verification:

- `Rulebook, extracted text lines 2854–2962 (page verification pending)`

FAQ takes precedence only where it directly addresses the question. A project adaptation must cite the official rule it changes and explain why the adaptation is needed.
