SOURCE ANCHOR: SPEND Ammo — half-full token

SOURCE TEXT:
If you have a half-full Ammo token and the game instructs you to spend it – discard it.

ASSERTION:
To spend half-full Ammo, discard the token.

VISUAL EVIDENCE:
The SPEND diagram shows the half-full token leaving play.
