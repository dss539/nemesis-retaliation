SOURCE ANCHOR: MALFUNCTION MARKERS 3. ON A ROBOT — unusable

SOURCE TEXT:
When placed on a Robot card, the Robot cannot be used in any way

ASSERTION:
A Robot whose card has a Malfunction marker cannot be used.

VISUAL EVIDENCE:
A Robot glyph follows “Robot.”

UNCERTAINTY:
none
