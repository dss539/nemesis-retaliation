RULEBOOK ASSERTION RB-P29-044
KIND: rule
PDF PAGE: 29
PRINTED PAGE: 29
SOURCE ANCHOR: INTERPLAY — consent and location

SOURCE TEXT:
It is possible to use an Item on another Character in the same Room, if the Character allows you to do so

ASSERTION:
An Item may affect another Character only if that Character is in the same Room and consents, subject to the listed effect classes.
