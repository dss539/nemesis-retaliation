SOURCE ANCHOR: 3. EVENT CARD RESOLUTION — Malfunction example

SOURCE TEXT:
If an effect instructs you to place a Malfunction marker in a Room, and that Room already has a Malfunction marker, ignore that effect.

ASSERTION:
An Event effect that would add a Malfunction marker to a Room already containing one is ignored.

VISUAL EVIDENCE:
A Malfunction glyph appears in the example.

UNCERTAINTY:
none
