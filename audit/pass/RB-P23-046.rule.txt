RULEBOOK ASSERTION RB-P23-046
KIND: rule
PDF PAGE: 23
PRINTED PAGE: 23
SOURCE ANCHOR: MALFUNCTION MARKERS 3. ON A ROBOT — duplicate

SOURCE TEXT:
If a Malfunction marker is to be placed on a Robot when there is one there already, simply ignore it.

ASSERTION:
Ignore an instruction to place a second Malfunction marker on a Robot.

none
