SOURCE ANCHOR: AUTODESTRUCTION TOKEN — trigger

SOURCE TEXT:
If a Round marker enters a space with the Autodestruction token, the Facility explodes and the game ends.

ASSERTION:
When the Round marker enters the Autodestruction token’s space, the Facility explodes and the game ends.

VISUAL EVIDENCE:
An Autodestruction glyph heads the callout.

none
