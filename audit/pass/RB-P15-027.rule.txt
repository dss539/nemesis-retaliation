SOURCE ANCHOR: 7. TIME ADVANCEMENT — final-space exception

SOURCE TEXT:
If the Round marker is already on the last space, proceed to the End of the Game instead.

ASSERTION:
If the Round marker is already on its final space, proceed to End of the Game instead of advancing it.
