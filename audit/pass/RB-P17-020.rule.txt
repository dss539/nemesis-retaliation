SOURCE ANCHOR: Suffocating token — discard by Active Life Support

SOURCE TEXT:
Discard this token when: ... end Turn in a Section with an [Active Life Support glyph].

ASSERTION:
Discard a Suffocating token when its Character ends a Turn in a Section with Active Life Support.

VISUAL EVIDENCE:
The token uses the Active-Life-Support glyph.

UNCERTAINTY:
none
