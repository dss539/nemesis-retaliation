SOURCE ANCHOR: EXPLORATION SEQUENCE 2b — existing Rooms

SOURCE TEXT:
If a Corridor leads to a Room that is already placed on the map, do not set it up.

ASSERTION:
Do not place an indicated Corridor that would connect to an already placed Room.
