SOURCE ANCHOR: Suffocating token — discard by gain

SOURCE TEXT:
Discard this token when: you gain [Oxygen glyph]

ASSERTION:
Discard a Suffocating token when its Character gains Oxygen.

VISUAL EVIDENCE:
The token uses an Oxygen glyph.

none
