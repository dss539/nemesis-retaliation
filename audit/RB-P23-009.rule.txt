SOURCE ANCHOR: FIRE MARKERS — duplicate placement

SOURCE TEXT:
If a Fire marker is to be placed in a Room with one already, simply ignore it.

ASSERTION:
Ignore an instruction to place Fire in a Room that already has Fire.
