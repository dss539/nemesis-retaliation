RULEBOOK ASSERTION RB-P37-022
KIND: rule
PDF PAGE: 37
PRINTED PAGE: 37
SOURCE ANCHOR: MALFUNCTION MARKER ON THE ROBOT — local repair

SOURCE TEXT:
If a Character is in a Room with the Robot, Actions that discard Malfunction markers may do so from the Robot.

ASSERTION:
A Character in the Robot’s Room may use a suitable effect to discard the Robot’s Malfunction marker.

VISUAL EVIDENCE:
none

UNCERTAINTY:
none
