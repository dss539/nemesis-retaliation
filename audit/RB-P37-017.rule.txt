SOURCE ANCHOR: DATA TOKEN AND ROBOT — remote benefit

SOURCE TEXT:
Characters with this token may Activate the Robot remotely without discarding the additional card.

ASSERTION:
A Character with a Data token pays no additional Action-card surcharge for remote Robot Activation.
