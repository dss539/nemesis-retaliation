KIND: rule
PDF PAGE: 40

SOURCE ANCHOR: SOLO/COOP WINNING — duplicate requirements

SOURCE TEXT:
If there are multiple Objectives requiring you to fulfill the same requirement ... that many Characters must do so and Survive.

ASSERTION:
When multiple Solo/Coop Objectives repeat a requirement, a separate surviving Character must fulfill each copy.

none
