SOURCE ANCHOR: INTRUDER HELP SHEET — Room ordinary token

SOURCE TEXT:
Place 1 Intruder of the type shown on the token in the Room.

ASSERTION:
An Adult, Drone, or Larva token resolved in a Room places 1 matching Intruder there.

VISUAL EVIDENCE:
The row pictures Larva, Drone, and Adult token faces.

UNCERTAINTY:
none
