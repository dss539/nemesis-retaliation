SOURCE ANCHOR: SOLO/COOP DIFFICULTY — Data shortage

SOURCE TEXT:
If ... Tasks require you to have more Data tokens than there are starting Characters ... gain as many as there are Characters in the game.

ASSERTION:
If Solo/Coop Tasks collectively demand more Data tokens than starting Characters, cap the required gains at one per Character.
